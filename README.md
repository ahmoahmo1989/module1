# الموديول الأول – تأسيس البيت الأيوبي وصعود صلاح الدين

برنامج تفاعلي (HTML/CSS/JS) لدليل الطالب – مقرر تاريخ الأيوبيين والمماليك، الفرقة الرابعة، كلية التربية بنين بالقاهرة – جامعة الأزهر.

- نقطة الدخول: `index.html`
- لا يحتاج خادمًا ولا تثبيتًا.
- بيانات الطلاب تُحفظ في متصفح كل جهاز (localStorage).
- لوحة الأستاذ: من الغلاف ← «لوحة الأستاذ» (الرقم السري الافتراضي `1234`، غيّره من الإعدادات).
